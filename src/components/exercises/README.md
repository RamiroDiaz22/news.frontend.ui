# 🏋️ Ejercicios Prácticos (Exámenes Junior)

Esta carpeta contiene ejercicios diseñados especialmente para practicar los conceptos fundamentales de React y TypeScript. Como desarrollador Junior, esto te servirá como un "campo de entrenamiento" seguro antes de tocar la lógica pesada de la aplicación.

## ¿Cómo funciona?

Cada carpeta contiene un componente vacío (`.tsx`) y un archivo de pruebas (`.test.tsx`).

**Tu objetivo es simple:**

1. Abre tu terminal y corre el comando de pruebas filtrando por el ejercicio que quieras resolver. Por ejemplo: `pnpm test 01-Props`
2. Verás que las pruebas fallan (letras rojas).
3. Abre el componente `.tsx` y lee los comentarios con los `TODO`. Ahí están las instrucciones de lo que debes programar.
4. Escribe el código necesario.
5. Si lo haces bien, la terminal se pondrá verde (éxito). ¡Esa es tu validación!

## Temario de Ejercicios

1. **01-Props**: Domina la creación de `interfaces` en TypeScript, el tipado estricto, paso de propiedades y el renderizado condicional.
2. **02-UseEffect**: Entiende el ciclo de vida, cómo hacer que un efecto se ejecute una sola vez y cómo manejar estados asíncronos simulados (Cargando...).
3. **03-EventsAndForms**: Practica componentes "controlados" (`value` + `onChange`), el manejo de estado (`useState`) y las validaciones simples antes de enviar un formulario.
4. **04-ListsAndFiltering**: Entiende cómo iterar arreglos en React usando `map()`, la importancia de la prop `key`, y cómo filtrar arreglos en base a un estado de búsqueda.

_Nota: Si te trabas, recuerda que puedes usar el **Mentor IA** para pedirle pistas, pero no le pidas que te resuelva el código._
